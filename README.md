## 📖 介绍

`astrbot_plugin_matrix` 是一款专为《淤积点》游戏设计的 AstrBot 查询插件。它整合了游戏中所有地区与武器的对应关系，帮助玩家快速定位武器刷取地点、优化刷取路线，提升资源获取效率。

插件内置了 **12 个地区** 和 **65 件武器** 的完整数据，支持：
- 📋 **武器列表**：按星级展示所有武器及编号。
- 🔍 **单个武器查询**：获取武器属性、可刷地点及推荐刷取方案。
- 🔗 **多武器组合优化**：寻找能同时刷取多把武器的地点和词条。
- 🏷️ **词条匹配查询**：按“基础/附加/技能”三个词条查找匹配的武器。

数据完全基于 JSON 文件，支持用户自定义扩展。

## 💿 安装

### 方法一：通过 AstrBot 插件市场安装（推荐）

1. 打开 AstrBot WebUI，进入 **插件管理** 页面。
2. 在 **插件市场** 中搜索 `astrbot_plugin_matrix`。
3. 点击 **安装**，等待完成即可。

### 方法二：手动安装

1. 下载插件源码：
   ```bash
   git clone https://github.com/Courison/astrbot_plugin_matrix.git
   ```
2. 将 `astrbot_plugin_matrix` 文件夹放入 AstrBot 的 `plugins` 目录。
3. 重启 AstrBot 容器或服务。

## 🎉 指令列表

| 指令 | 权限 | 说明 | 示例 |
| :--- | :--: | :--- | :--- |
| `/基质 武器` | ALL | 显示所有武器列表（6星在前，5星在后），以图片形式返回 | `/基质 武器` |
| `/基质 <武器名/编号>` | ALL | 查询单个武器详情，包括属性、可刷地点及推荐刷取方案 | `/基质 四二式` 或 `/基质 42` |

| `/基质 基础/附加/技能` | ALL | 按三个词条精确匹配武器，返回可刷地点和武器列表 | `/基质 力量/生命/迸发` |
| 其他输入 | ALL | 显示帮助文档 | `/基质 随便打` |

## 📊 数据文件说明

插件数据来源于两个 JSON 文件，位于插件根目录下，支持用户自定义扩展：

### `area.json` — 地区数据

```json
[
  {
    "name": "枢纽区",
    "group": "四号谷地",
    "base": ["敏捷", "力量", "意志", "智识", "主能力"],
    "extra": ["攻击", "灼热伤害", "电磁伤害", "寒冷伤害", "自然伤害", "源石技艺", "终结技效率", "法术伤害"],
    "skill": ["强攻", "压制", "追袭", "粉碎", "巧技", "迸发", "流转", "效益"]
  }
]
```

| 字段 | 说明 |
| :--- | :--- |
| `name` | 地区名称 |
| `group` | 所属区域（`四号谷地` / `武陵`） |
| `base` | 该地区可刷的基础属性列表 |
| `extra` | 该地区可刷的附加属性列表 |
| `skill` | 该地区可刷的技能属性列表 |

### `weapon.json` — 武器数据

```json
[
  {
    "id": 1,
    "name": "钢铁余音",
    "star": "5星",
    "type": "单手剑",
    "base": "敏捷",
    "extra": "物理伤害",
    "skill": "巧技"
  }
]
```

| 字段 | 说明 |
| :--- | :--- |
| `id` | 武器唯一编号（用于数字查询） |
| `name` | 武器名称（支持模糊匹配） |
| `star` | 星级（`5星` / `6星`） |
| `type` | 武器类型（`单手剑`、`双手剑`、`长柄武器`、`手铳`、`施术单元`） |
| `base` | 基础属性 |
| `extra` | 附加属性 |
| `skill` | 技能属性 |

## 🧠 插件工作流程

1. **消息接收**：监听所有以 `/基质` 开头的消息。
2. **指令解析**：根据消息内容判断操作类型（武器列表、单个查询、组合优化、词条查询）。
3. **数据匹配**：
   - **武器名/编号**：模糊匹配武器名称或精确匹配编号。
   - **多武器**：解析逗号/顿号分隔的武器名或编号。
   - **词条**：按 `/` 分割的三个词条进行精确匹配。
4. **推荐计算**（单个武器查询时）：
   - 遍历所有地区，找出能刷到目标武器的地区。
   - 对每个地区，枚举 3 个基础属性 + 1 个附加/技能属性的组合。
   - 统计每个组合能刷到的武器数量，选出附带武器最多的方案。
   - 分别输出“附加最佳”和“技能最佳”两种推荐。
5. **组合优化**（多武器查询时）：
   - 遍历所有地区及词条组合，计算能命中的目标武器数。
   - 优先选择命中数最多的组合，若命中数相同则选择附带武器总数最多的。
6. **结果返回**：以纯文本格式返回查询结果。

## 🧩 扩展指南

### 添加新武器

在 `weapon.json` 末尾追加新武器对象，`id` 必须唯一且递增：

```json
{
  "id": 66,
  "name": "新武器名称",
  "star": "6星",
  "type": "施术单元",
  "base": "敏捷",
  "extra": "攻击",
  "skill": "迸发"
}
```

### 添加新地区

在 `area.json` 末尾追加新地区对象：

```json
{
  "name": "新地区",
  "group": "武陵",
  "base": ["敏捷", "力量", "意志", "智识", "主能力"],
  "extra": ["攻击", "生命", "灼热伤害"],
  "skill": ["强攻", "粉碎", "昂扬"]
}
```

> **注意**：修改 JSON 文件后无需重启插件，下次查询时自动生效。
